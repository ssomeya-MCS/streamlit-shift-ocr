手書き勤務シフト表 OCR（固定レイアウト版）

ファイル構成
- app.py           Streamlitアプリ
- requirements.txt Python依存ライブラリ
- packages.txt     Streamlit Cloud/Linuxのシステム依存ライブラリ

想定環境
- Streamlit Community Cloud
- Python 3.11
- PaddleOCR 2.10.0 / PaddlePaddle 2.6.2

使い方
1. GitHubリポジトリの app.py / requirements.txt / packages.txt を置き換えます。
2. Streamlit Community CloudのPython設定を3.11にします。
3. 再デプロイ後、シフト表のサンプルをアップロードします。
4. テンプレート設定で、1日列と31日列の中心、氏名欄の左右、最初の職員行の中心、行間隔、行数を調整します。
5. プレビュー上で青枠（氏名欄）、赤線（日付列中心）、緑枠（職員行の切り出し）が表に合っていることを確認します。
6. 「現在のテンプレート設定をJSONで保存」でテンプレートを保存します。翌月以降は設定JSONを読み込めます。
7. 固定レイアウトでOCRを実行し、結果を画面上で修正した後、Excelをダウンロードします。

Excel出力
- 勤務シフト表: 1列目が氏名、2～32列目が1日～31日
- OCR確認: 実際に認識したセル、信頼度、判定、セル位置
- 処理情報: 対象年月、施設名、設定など

注意
- このコードは、シフト表がほぼ同じ位置・大きさ・向きでスキャンされることを想定しています。
- 認識専用モードでセルを個別に認識します。空欄セルはOCR対象から外します。
- 座標設定は初回に調整し、JSONとして保存できます。
- 固定レイアウトでも手書き文字の誤認識は残ります。勤務データとして使用する前に原本確認が必要です。
- 初回はPaddleOCRモデルのダウンロードが発生します。無料のStreamlit CloudではCPU制限・メモリ制限により処理時間が長くなる可能性があります。
- 実際の職員情報を含むシフト表をクラウドにアップロードする前に、組織の情報管理ルールを確認してください。
